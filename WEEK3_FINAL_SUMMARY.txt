🔍 ARTIFACT TYPES GENERATED
================================================================================

HTML REPORT
  📊 Generated: Always
  📁 Location: index.html (in test-results/playwright/)
  💡 What: Summary of all tests, pass/fail status, timing
  🎯 Use: View in browser to get overview of test results

TRACES
  🔍 Generated: On first retry
  📁 Location: test-results/[browser]/trace.zip
  💡 What: Detailed execution logs, DOM snapshots, network requests
  🎯 Use: Open with 'npx playwright show-trace [trace-file]'

SCREENSHOTS
  📸 Generated: Only on test failure
  📁 Location: test-results/[browser]/[test-name]/screenshots/
  💡 What: Visual state of UI when test failed
  🎯 Use: Review what the app looked like when test failed

VIDEOS
  🎥 Generated: Only on test failure
  📁 Location: test-results/[browser]/[test-name]/video.webm
  💡 What: Full video recording of test execution
  🎯 Use: Play in browser/video player to see exact steps

📋 COMMANDS YOU'LL USE
================================================================================

Run all tests locally:
  npm run e2e

Run tests in specific browser:
  npx playwright test --project chromium

  npx playwright test e2e/expense-workflow.spec.ts

Run tests matching pattern:
  npx playwright test --grep "validation"

View test traces:
  npx playwright show-trace test-results/playwright/trace.zip

Install browsers:
  npx playwright install --with-deps
